# v0.21.0 リリースノート

作成日：2026-11-26。GitHub Releases に載せる本文の元になる文面です。アイテムの説明を見やすくし、出目調整券に±2・±3を加えました。ルールとセーブ形式が変わるため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」に当たります。事前の予告は、作者の判断で省きました（v0.10.0・v0.14.0 と同じ扱い）。

## 公開時の本文

### v0.21.0：出目調整券に±2・±3が加わり、アイテムの説明が見やすくなりました

**出目調整券が3種類になりました**

- 「出目調整券±1」「出目調整券±2」「出目調整券±3」の3種類です。±2の券は出目に2を足すか引くか、±3の券は3を足すか引くかを選べます。
- 調整した出目は6を超えてもかまいません（6に+3で9マス進めます）。1より小さくはできません。
- ±2・±3の券は±1より出にくく、±1・±2・±3は 3:2:1 の割合で出ます。アイテムを拾う確率と、不利なアイテムの割合は変わりません。

**アイテムの説明が見やすくなりました**

- 遅延・運休などの効果（画面の「遅延 あと3」などの表示）を押すと、その効果の説明が開きます。PC ではマウスを乗せるだけでも表示されます。
- 不利なアイテムを拾ったときのお知らせに、何が起きるかを書くようにしました（例：「3ターン後の出目が1になります」）。
- 不利なアイテムの説明で、使う時期を「拾うと自動で発動」と正しく表示するようにしました。

**出目を調整しながら地図を動かせるようになりました**

- 出目調整券を使うかどうか選んでいる間も、地図を動かしたり拡大・縮小したりして、行き先を確かめられます。選び終わると、地図は元どおり駒を追いかけます。

**途中のセーブデータについて**

ゲームのルールが変わるため、この更新より前に始めた途中のセーブは再開できません。開くと「ゲームのルールが変わったため、このセーブデータは続きから遊べません。」と表示されます。セーブデータの移行はありません。その画面からセーブを破棄して、新しいゲームを始められます。
