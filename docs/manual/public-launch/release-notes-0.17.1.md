# v0.17.1 リリースノート

作成日：2026-11-20。GitHub Releases に載せる本文の元になる文面です。抽選の結果の行が HUD へ飛んで収まる位置が、Safari などで数 px ずれることがあったのを直しました。ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.17.1：抽選の結果が、HUD の正しい位置に収まるように

背の低いスマホ画面で抽選ボードが縮んで表示されるとき、Safari などの WebKit 系ブラウザでは、決まった路線と方向の行が HUD へ飛んで収まる位置が数 px ずれることがありました。行の位置を測り終えてから飛ぶ動きを始めるようにして、ずれないようにしました。

- 見た目の動きや速さは変わりません。
- ルールは変わらず、出目や抽選の結果も今までと同じです。
- 以前のセーブデータは、そのまま続きから遊べます。
