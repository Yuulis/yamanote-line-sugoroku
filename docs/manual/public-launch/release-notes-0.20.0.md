# v0.20.0 リリースノート

作成日：2026-11-25。GitHub Releases に載せる本文の元になる文面です。乗り換えの抽選（パタパタ表示）を、路線が決まってから方向をめくる順番に変えました。ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.20.0：路線が決まってから、方向をめくる

乗り換えの抽選は、まず路線をめくり、路線が止まってから方向をめくるようになりました。路線が決まるまでは方向の行に「方向 ？」が出るので、方向の表示から先に路線が分かってしまうことはありません。山手線に決まったときは、路線が止まると同時に「外回り」が出ます。

方向が決まったあとは少し止まってから次へ進むので、どちらに乗るのかを読み取れます。めくっている途中の長い路線名も省略されずに表示され、スマホでは2行に折り返して全部見えるようにしました。

## 変更（内部メモ）

- 抽選のめくりを「路線 → 方向」の順に変更。方向のめくりは路線のめくり時間の0.4倍（ふつうで0.64秒）。山手線のように方向が1つの路線は、路線が止まると同時に方向を表示します。方向だけを抽選するときは、その短い時間だけめくります。
- 結果が出たあと、路線のめくり時間の0.25倍（ふつうで0.4秒）止めてから HUD へ移ります。ふつうの速度で抽選のめくりは、路線と方向の両方を抽選するとき2.64秒（従来1.6秒）、山手線のとき2.0秒、方向だけのとき1.04秒です。
- ボードの大きさを、決まった名前ではなく候補すべての名前から決めるように変更しました。めくり中の長い候補名が省略されず、ボードの大きさからも結果が分かりません。PC のボードの最大幅を 26rem から 27rem にしました。
- スマホ（幅600px以下）では路線名を2行まで折り返します。2行に収まらない長い名前は、文字数に応じて85%か70%の大きさにします。PC の表示は変わりません。
- 山手線が1/2で選ばれる重みは、パタパタでは表示しません。
- 対応する PR：#129（Issue #63）。リリース PR に `Closes #63` を記載します。
- `dataVersion`、ルール、抽選の結果と確率、セーブ形式、公開データに変更はありません。途中のセーブデータはそのまま続きから遊べます。演出の仕様を変えたため、アプリの版をマイナー番号で上げます（0.19.0 → 0.20.0）。
