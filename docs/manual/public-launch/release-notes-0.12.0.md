## 公開時の本文

### v0.12.0：サイコロ・到着・抽選・アイテムに演出がつきました

1ターンの流れが目で追えるように、サイコロを振ってからアイテムを拾うまでに短い演出を加えました。ルールは変わらず、出目や抽選の結果も今までと同じです。

**ターンの演出**

- サイコロが転がって、出た目で止まります。倍速券や出目調整などが効いたときは、その印が押されます。
- 駅に着くと、「到着」の札が出ます。新しく踏破した区間は、地図の上で光ります。
- 路線や方向の抽選があったときだけ、駅の発車案内のようなパタパタ表示で結果が決まります。その後、パネルの「乗車中」の欄へ収まります。
- アイテムを拾うと、アイコンが持ち物の欄へ飛んでいきます。持ち物が満杯のときは、飛び終わってから「捨てるアイテムを選ぶ」画面が開きます。
- ゴールしたターンは、到着の札が出たあとにクリア画面になります。

**操作**

- 演出の長さは、設定の「速度」に合わせて変わります。速度を途中で変えた場合は、次のターンから反映されます。
- 演出は「スキップ」か、演出の表示をタップすると、まとめて終えられます。捨てる選択などの必要な操作は残ります。
- 演出の途中は「サイコロを振る」が押せません。持ち物のカードを開いて中身を見ることはできます。
- 結果は演出が終わってから、パネル・地図・ログ・読み上げに出ます。演出より先に結果が見えることはありません。
- 端末の設定で動きを減らす表示（「視差効果を減らす」など）を有効にしている場合と、途中から再開した場合は、演出なしで結果がすぐ出ます。
- 画面の小さいスマホや横向きでは、演出が地図のボタンに重ならない場所に出ます。

**ご注意**

- ルール、アイテム、確率、路線データ、セーブ形式、結果の共有文は変わっていません。
- 以前のセーブデータは、そのまま続きから遊べます。
