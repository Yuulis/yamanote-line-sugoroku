作成日：2026-11-09。GitHub Releases に載せる本文の元になる文面です。長い試合のテンポを上げる設定と「おまかせで進む」を加えました。ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.13.0：「とても速い」・演出の設定・「おまかせで進む」で、長い試合もテンポよく

長い試合で同じ操作を何度も繰り返さずに済むように、速さと演出を選べるようにしました。決めることがないターンは、自動で進めることもできます。ルールは変わらず、出目や抽選の結果も今までと同じです。

**おまかせで進む**

- 「サイコロを振る」の横に「おまかせ」ボタンを置きました。ON にすると、振れる状態になってから約1.2秒ごとに自動でサイコロを振ります。
- アイテムを拾うと、そのターンの結果が出たところで OFF に戻ります。不利なアイテムを拾ったときも同じです。拾ったアイテムを使うかどうかは、自分で決められます。
- 出目調整と捨てるアイテムの選択は、自動では答えません。答えると、おまかせはそのまま続きます。持ち物が満杯で、拾ったアイテムのほうを捨てた場合も続きます。
- メニューやログ、アイテムのカードを開いている間と、使うアイテムを選んでいる間は、自動では振りません。
- タブを切り替えて画面が隠れると OFF になります。おまかせの ON は保存されず、再読み込みや新しいゲームでは OFF から始まります。

**速度と演出**

- 速度に「とても速い」を加えました。駅から駅へすばやく進み、到着の札は出ません。新しく踏破した区間は、地図の上で光ります。
- メニューに「演出」を加えました。「すべて」は今までどおりです。「重要なときだけ」は、サイコロの転がりと到着の札を省き、抽選・新しく踏破した区間の光・アイテムの取得・ゴールだけを残します。「なし」は演出を出さず、駅から駅への移動が終わったところで結果を出します。
- 演出を変えた場合は、次のターンから反映されます。
- 端末の設定で動きを減らす表示（「視差効果を減らす」など）を有効にしている場合は、今までどおり演出なしで結果がすぐ出ます。

**設定の保存とキーボード**

- 速度・追尾・演出の設定を、この端末のブラウザに保存するようにしました。再読み込みしても、新しいゲームを始めても、前の設定のままです。地図を手で動かして追尾が切れた状態は保存されません。
- キーボードの Space または Enter でサイコロを振り、S または Escape で演出をスキップできます。ダイアログやメニューを開いているとき、ボタンにフォーカスがあるときは、今までどおりそちらの操作が優先されます。
- メニューの中に、キーボード操作の説明を載せました。

**ご注意**

- ルール、アイテム、確率、路線データ、セーブ形式、結果の共有文は変わっていません。
- 以前のセーブデータは、そのまま続きから遊べます。
