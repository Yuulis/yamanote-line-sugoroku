## v0.10.0（大型更新）として本番公開済み（2026-10-27、PR #49）

| 項目 | 内容 | PR |
|---|---|---|
| アイテム制（A6） | 駅でアイテムを拾って使うルールに変更。抽選の偏りを弱め（山手線 1/2、向き 3:2）、セーブ形式を v4 に変更 | #47 |

- [配信とデータ更新の方針](data-update-policy.md)の「大型更新」に当たるため、アプリの版をマイナー番号で上げる（0.9.0 → 0.10.0）。
- 宣伝を始める前のため、作者の判断で予告はせずに公開した。公開時の本文は [GitHub Releases の v0.10.0](https://github.com/Yuulis/yamanote-line-sugoroku/releases/tag/v0.10.0) に載せた（下書きは[リリースノート](release-notes-0.10.0.md)）。
- 公開後の確認：本番の JS に v0.10.0 とアイテム制のルールが入っていること、E2E 専用の切り替えが含まれないこと、`/assets/*` が1年の immutable、HTML と `/data/*` が `max-age=0, must-revalidate` であることを確認した。
- 未確認：スマホ実機での動作の重さとタッチ操作、読み上げソフトでの読み上げ。
