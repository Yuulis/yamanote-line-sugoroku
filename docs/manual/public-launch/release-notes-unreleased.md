# 次回リリースノート（作業中）

次回リリース用の作業メモです。版が決まり次第、`release-notes-<version>.md` に改名します。

## 公開時の本文

### 長い日本語を読みやすい位置で折り返す

HUD、路線バッジ、アイテムのダイアログ、出目調整、パネルの経路・候補一覧、クリア画面で、長い日本語が空白や括弧、「・」「–」の区切り、「方面」の前などで折り返されるようになりました。Chromium では長い文章の文節も見て、折り返す位置を選びます。

途中で分けられない語が表示枠より長い場合は、枠内に収めるため語の途中で折り返すことがあります。

### スマートフォンのHUD表示

スマートフォンでは路線名と方面名を最大2行で表示し、続きは省略記号で示します。値は15px、項目名は13pxです。デスクトップと横幅の短い画面ではHUDを1行に保ち、長い表示を省略します。省略されても、全文は `title` 属性とログに残ります。

### ボタンの折り返し

短いボタン名は1行のまま表示します。ダイアログとクリア画面ではボタンの並びがボタン単位で次の行に移り、390px以下の画面ではクリア画面の操作を縦に並べます。

### ご注意

- 幅320pxのスマートフォンでは方面欄に約5文字しか入りません。最も長い方面名「羽田空港第1・第2ターミナル方面」は単語の途中で折り返したうえで、残りは省略記号で表示されます。
- 日本語の本文は左揃えのままです。両端揃えも試しましたが、文字間が不自然に広がるため採用しませんでした。
- ゲームエンジン、乱数、セーブ形式、路線データは変更していません。
