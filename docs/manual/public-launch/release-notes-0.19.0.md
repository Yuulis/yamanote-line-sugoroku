# v0.19.0 リリースノート

作成日：2026-11-24。GitHub Releases に載せる本文の元になる文面です。クリア画面で旅の軌跡を再生し、結果の画像を X で共有・保存できるようにしました。ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.19.0：旅の軌跡を振り返って、Xでシェア

クリア画面で、通ったルートを地図上で再生できるようになりました。ターンごとの字幕と速度変更、一時停止を使って、旅を振り返れます。最長の乗車や一番遠くまで行った駅などのハイライトも表示し、移動履歴は「移動履歴を見る」から一覧で確認できます。

「Xでシェア」では、通ったルート全体を地図に描いた画像を、結果の文章と一緒に共有できます。「画像を保存」から PNG として保存することもできます。

## 変更（内部メモ）

- クリア画面にハイライト（最長の乗車、最も使った路線、一番遠くまで行った駅、使ったアイテム、避けた不利なアイテム）を追加。移動履歴はダイアログで確認でき、スマホでは軌跡の再生中にカードを操作用の帯へ畳みます。
- 地図には通ったルートだけを色付きで表示し、カメラにルート全体を収めます。ターンごとにルートが伸びる再生、字幕、速度切替、一時停止・再開に対応しました。OS の「視差効果を減らす」設定では全ルートをすぐ表示します。
- ルート全体の PNG を作成し、「Xでシェア」「画像を保存」を追加しました。スマホでは画像と文章を共有シートに渡し、PC では画像をクリップボードにコピーして X を開きます。
- `result_share` に `x` と `save` の計測を追加し、プライバシーポリシーに X への移動と共有の計測を追記しました。
- 対応する PR：#125（Issue #69）。ランキング機能は #124 に分けました。リリース PR に `Closes #69` を記載します。
- `dataVersion`、ルール、セーブ形式、公開データに変更はありません。途中のセーブデータはそのまま続きから遊べます。新しい機能を加えたため、アプリの版をマイナー番号で上げます（0.18.1 → 0.19.0）。
