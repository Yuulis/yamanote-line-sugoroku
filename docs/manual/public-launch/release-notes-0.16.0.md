# v0.16.0 リリースノート

作成日：2026-11-17。GitHub Releases に載せる本文の元になる文面です。山手線一周までの進み具合と、寄り道中の手応えがわかるようにしました。表示だけの変更で、路線データ・セーブ形式・ルールは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### 山手線一周までの進み具合が、わかりやすくなりました

- 山手線以外の路線に乗っているときは、「山手線まで あと3駅（近づく）」のように、山手線までの駅数と、今の向きで近づいているか遠ざかっているかを表示します。
- 踏破が 10・20・25・29 区間に届いたときに、「あと1区間！」などのお知らせを出し、進捗バーを光らせます。演出を減らす設定のときは光りません。
- 「訪れた駅 73/1,586」「乗った路線 11/134」のように、これまでに停車した駅と乗った路線の数を数えます。PC では HUD に、スマホではメニューの中に、クリア画面ではまとめとして表示します。快速で通過した駅は数えません。

### スマホでは、ログと設定を「メニュー」にまとめました

- 画面の幅が狭いスマホでは、ログと設定（凡例を含む）を1つの「メニュー」ボタンにまとめ、地図を広く見られるようにしました。開くと、まず直前のターンのログが出ます。
- 地図の左下の札を押すと、メニューがログの画面で開きます。

### そのほか

- 画面上部の「山手線すごろく 東京近郊版」の見出しを省き、そのぶん HUD に余裕を持たせました。

**途中のセーブデータについて**

セーブデータの形式と路線データは変わらないため、更新前の途中のセーブは、そのまま続きから遊べます。訪れた駅と乗った路線の数も、これまでの移動の記録から数えます。

## 公開時の対応（内部メモ）

- 路線データの版（`dataVersion`）は `n02-2025-7974da15af8e` のままです。[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たらないため、予告は要りません。
- 新しい表示を加えたので、アプリの版はマイナー番号で上げます。今回は 0.15.0 → 0.16.0 とします。
- 既知の制限：お知らせの文が、スキップしたときや持ち物を選び直したときに、読み上げで繰り返されることがあります（Issue #96）。
