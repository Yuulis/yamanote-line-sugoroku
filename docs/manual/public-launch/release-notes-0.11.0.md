# v0.11.0 リリースノート

作成日：2026-11-03。GitHub Releases に載せる本文の元になる文面です。画面の見た目と操作が大きく変わりましたが、ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.11.0：画面をゲームらしく見やすくしました

ゲーム中の画面を作り直しました。今の駅や進み具合がひと目でわかり、アイテムも絵で選べます。ルールは変わらず、同じ遊び心地のままです。

**ゲーム画面**

- ゲーム中のパネルに、乗車中の路線、今の駅、ターン数、踏破区間を並べました。サイコロの出目は短い表示にしました。
- 「サイコロを振る」ボタンは、いつも同じ場所にあります。表示される情報が増えても動きません。
- ログとメニューは、必要なときだけ開く「ログ」「メニュー」に分けました。ログを開くと、このターンの出目などが先頭にまとめて出ます。
- アイテムを拾う・使うなどの通知は、短い一言で表示します。

**アイテム**

- 持ち物は、アイコンと短い名前のタイルで並びます。
- タイルを押す（タップする）と、効果を書いたカードが開き、「使う」「閉じる」を選べます。パソコンでは吹き出し、スマホでは下から出るシートで表示します。
- 持ち物が満杯のときの「捨てるアイテムを選ぶ」画面には、4枚のカードが並びます。

**スマホなどでの見やすさ**

- スマホの縦向き・横向きに合わせた配置にしました。
- キーボードの Tab キーは、画面に見える順に進みます。
- iPhone のノッチなど、画面の欠けた部分を避けて表示します。
- スマホでは、地図の出典表記を最初は折りたたみました。ⓘ をタップすると読めます。通知が出典表記に重ならなくなりました。

**ご注意**

- ルール、アイテム、確率、路線データ、セーブ形式、結果の共有文は変わっていません。
- 以前のセーブデータは、そのまま続きから遊べます。

## 公開の判断（内部メモ）

- 画面が大きく変わったため、アプリの版はマイナー番号で上げる（0.10.0 → 0.11.0）。
- 凍結中の項目（路線データ、ルール、セーブ形式）は変えていないので、[大型更新](data-update-policy.md)には当たらない。予告は不要で、GitHub Releases への本文掲載だけで足りる。
- 対応する PR は #52（`feature/ui-pop-hud-inventory`）。
