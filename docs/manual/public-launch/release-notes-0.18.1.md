作成日：2026-11-22。GitHub Releases に載せる本文の元になる文面です。スクリーンリーダーで遊ぶときに、節目の文（「10区間突破！」「新橋に着けばクリア」など）が同じターンの中で何度も読まれることがあったのを直しました。ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.18.1：節目の読み上げを1回にしました

スクリーンリーダーで遊ぶとき、節目の文（10・20・25・29区間の突破と、30/30 の「新橋に着けばクリア」）が、同じターンの中で何度も読まれることがありました。

- 到着の表示や抽選の途中で「演出をスキップ」を押したときに、到着時と結果の表示時の2回読まれていたのを、1回にしました。
- 演出なしや、OS の「視差効果を減らす」を使っているときに、アイテムを選ぶ・外す、捨てるアイテムを選ぶたびに読み直されていたのを、1回にしました。
- 区間の点滅も抽選も出ないターンでは、節目の文が読まれていませんでした。結果の表示のときに1回読むようにしました。
- 続きから遊ぶときは、これまでどおり読まれません。
- トーストと進捗バーの点滅は変わりません。
- ルールは変わらず、出目や抽選の結果も今までと同じです。
- 以前のセーブデータは、そのまま続きから遊べます。

## 公開の判断（内部メモ）
