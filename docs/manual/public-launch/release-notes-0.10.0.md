## 公開時の本文

### v0.10.0：アイテム制になりました

駅でアイテムを拾い、使いどころを考えて進むすごろくになりました。サイコロ任せだったこれまでと違い、乗る路線や進む向きを自分で選べる場面があります。

**アイテムの拾い方と使い方**

- ターンの最後に止まった駅で、30%の確率でアイテムを拾います。そのうち30%は不利なアイテムです。
- アイテムは3つまで持てます。満杯のときは、新しく拾ったものと合わせた4つから1つを選んで捨てます。
- 使えるのは1ターンに1つで、サイコロを振る前に選びます。出目調整券だけは、出目を見てから使います。

**アイテムの種類**

| アイテム | 効果 |
|---|---|
| 路線指定券 | 今いる駅で、乗る路線を選べる（向きは抽選） |
| 方向指定券 | 山手線以外の路線で、進む向きを選べる |
| 出目調整券 | 出目を見てから ±1 できる |
| 倍速券 | この回の出目が2倍になる |
| 快速券 | 2路線以上が止まる駅だけを1駅と数えて進む |
| 回送列車 | いちばん近い山手線の駅へ移る（サイコロは振らない） |
| 遅延証明書 | 持っているだけで、次に拾う不利なアイテムを1回打ち消す |
| 遅延（不利） | 3ターン後の出目が1になる |
| 運休（不利） | その路線に5ターン乗れない |
| 寄り道（不利） | 次の乗換駅で、別の路線へ乗り換える |
| 寝過ごし（不利） | 次のターンは終点まで運ばれる（環状線は6駅） |

**抽選の変更**

- 乗換駅で山手線が当たる確率を、2/3 から 1/2 にしました。
- 山手線以外の路線で、山手線に近づく向きの重みを 2:1 から 3:2 にしました。

アイテムを上手に使うと、クリアまでの目安はこれまでと同じくらい（中央値で約65ターン）です。

- 路線データは変わっていません。
