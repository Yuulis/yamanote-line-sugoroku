# クレジットとアクセス解析

クレジット画面では、鉄道データ・地図・ライブラリ・書体の出典、ソースコード、お問い合わせ先、アプリと路線データのバージョンを確認できます。タイトル画面の「クレジット」から開けます。

Google Analytics 4 では閲覧ページ、参照元、端末・ブラウザーの種類、おおよその地域、ゲームの開始・クリア・共有・エラーの件数を計測します。セーブ、乱数シード、駅 ID、移動履歴は送信しません。計測はクレジット画面の「アクセス解析を許可する」のチェックを外すと無効になります。

本番の計測を有効にするには、Vercel の **Project → Settings → Environment Variables** で `VITE_GA_MEASUREMENT_ID` に GA4 の測定 ID（`G-...`）を設定し、Production 環境に適用して再デプロイします。未設定時は計測スクリプトを読み込みません。

タイトル画面の下部にアプリバージョンを表示し、クレジット画面にアプリのバージョンとコミット、路線データのバージョンを表示します。
