# v0.17.0 リリースノート

作成日：2026-11-18。GitHub Releases に載せる本文の元になる文面です。ルールをいつでも読み直せるようにし、タイトル画面とセーブまわりをわかりやすくしました。表示と案内だけの変更で、路線データ・セーブ形式・ルールは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### 「遊び方」をいつでも読めるようになりました

- タイトル画面とゲーム中のメニューに「遊び方」を追加しました。ゴール、乗換駅での抽選の確率、アイテムの一覧と効果、設定と操作、セーブについてまとめています。
- ゲーム中に開いても、進行はそのままです。閉じると続きから遊べます。
- 抽選結果の「詳しく」から抽選のルールへ、アイテムカードの「詳しく」からアイテムの説明へ、直接移れます。
- タイトル画面の説明文は、目標がすぐわかるように3文に短くしました。

### タイトル画面とセーブがわかりやすくなりました

- 「つづきから」に、踏破した区間と次に遊ぶターンを表示します（例：「つづきから　踏破 4/30・3ターン目・品川」）。これまで1ターンずれていた表示も直しました。
- 「セーブを削除」は、「つづきから」の下の小さなリンクにしました。
- 1ターン目を終えたときに一度だけ、「自動で保存しています。いつでも閉じて、続きから遊べます」とお知らせします。
- 画面上部の ✓ を押すと、保存の状態を説明します。
- タイトル画面の背景に、山手線のループが映るようにしました。地図の読み込み中は、ループの簡易図を表示します。タイトル画面では使えない地図のボタンは隠しました。

**途中のセーブデータについて**

セーブデータの形式と路線データは変わらないため、更新前の途中のセーブは、そのまま続きから遊べます。

## 公開時の対応（内部メモ）

- 路線データの版（`dataVersion`）は `n02-2025-7974da15af8e` のままです。[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たらないため、予告は要りません。
- 新しい画面を加えたので、アプリの版はマイナー番号で上げます。今回は 0.16.0 → 0.17.0 とします。
- 既知の制限：読み込み中と通信に失敗したときの「遊び方」は、路線データがないため「山手線」「新橋」の代わりに「目標路線」「出発駅」と表示します。タイトルの山手線ループは、中央のカードに大部分が隠れます。
