# v0.14.0 リリースノート

作成日：2026-11-12。GitHub Releases に載せる本文の元になる文面です。地図を見ながら進行方向・残りの区間・クリアまでの道筋・出目調整の行き先を確かめられるようにしました。方面表示を直したため路線データの版が変わり、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」に当たります。

## 公開時の本文

### 地図を見ながら、進行方向や行き先を確かめられるようになりました

- 方面表示を、路線の実際の終点に合わせて修正しました。
- 山手線の未踏破区間を地図上で強調し、現在地のマーカーには進行方向を表示します。
- 山手線の30区間をすべて踏破すると、「あとは新橋に着けばクリア」と案内します。地図上の新橋も目印で示し、到着前に一度お知らせします。
- 出目を調整するとき、選択肢に行き先を表示します。地図上の吹き出しでも各候補の行き先と進むマス数を確認できます。

**途中のセーブデータについて**

路線データの版が変わるため、更新前の路線データで始めた途中のセーブは再開できません。旧版のセーブを開くと「路線データが更新されたため、このセーブデータは使えません。」と表示されます。セーブデータの移行はありません。

## 公開時の対応（内部メモ）

- [配信とデータ更新の方針](data-update-policy.md)では、`dataVersion` の変更を路線データの変更として扱います。この更新は既存セーブを再開できなくするため、大型更新として公開する扱いです。
- 同方針に従い、公開前に GitHub Releases と X で予告し、公開時の GitHub Releases に変更内容と旧版セーブを再開できないことを記載します。
- 方針では大型更新時にアプリのマイナー番号を上げることも定めています。今回は 0.13.1 → 0.14.0 とします。
