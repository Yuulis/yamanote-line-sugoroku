# v0.15.0 リリースノート

作成日：2026-11-15。GitHub Releases に載せる本文の元になる文面です。直前のターンの結果を、いつでも見返せるようにしました。表示だけの変更で、路線データ・セーブ形式・ルールは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### 直前のターンの結果を、いつでも見返せるようになりました

- PC・タブレットでは、サイコロの下に「前のターン」のカードを常に表示します。出目と着いた駅、乗った路線と方面、新しく踏破した区間数、乗換、拾ったアイテムや使った効果が一目でわかります。
- スマホでは、地図の左下に「3 → 半蔵門 +1区間」のような小さな札を出します。押すと、そのターンのログが開きます。
- スマホを横向きにしたときなど、画面の高さが低いときは、サイコロの下に1行にまとめて表示します。
- スマホの HUD では、札と重複する出目の表示を省きました。
- サイコロや抽選などの演出と、出目調整のときに地図に出る吹き出しは、札に重ならない位置に出ます。高さの低い画面では、抽選のボードを縮めて収めます。

**途中のセーブデータについて**

セーブデータの形式と路線データは変わらないため、更新前の途中のセーブは、そのまま続きから遊べます。

## 公開時の対応（内部メモ）

- 路線データの版（`dataVersion`）は `n02-2025-7974da15af8e` のままです。[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たらないため、予告は要りません。
- 新しい表示を加えたので、アプリの版はマイナー番号で上げます。今回は 0.14.0 → 0.15.0 とします。
- 開発側の CI の変更（#83：作業ブランチでの E2E の絞り込み、WebKit・PC の Chromium の分割）も同じ版に入りますが、利用者には関係がないため公開時の本文には載せません。
