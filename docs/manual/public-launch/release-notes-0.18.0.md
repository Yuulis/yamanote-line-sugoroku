# v0.18.0 リリースノート

作成日：2026-11-21。GitHub Releases に載せる本文の元になる文面です。初めて遊ぶ人に向けた最初の案内と一度だけ出るヒントを加え、スキップのボタンの表記をわかりやすくしました。あわせて、正しく動いていなかった「おまかせ」を削除しました。表示と案内だけの変更で、路線データ・セーブ形式・ルールは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### 初めて遊ぶ人への案内を加えました

- 初めて新しいゲームを始めるときに、サイコロ、踏破区間、地図の3ステップで遊び方を案内します。「前へ」「次へ」「とばす」「はじめる」で進められます。
- ゲーム中の「遊び方」にある「最初のガイドをもう一度見る」から、もう一度見られます。
- 前に遊んだ形跡がある人（セーブがある、自動保存のお知らせを見た、ガイドを始めたことがある）には出ません。
- ターンの結果が出たあとに、抽選・山手線以外の路線に乗ったときの向き・アイテム・不利なアイテム・余った出目のある終点について、状況に合ったときだけ一度ずつヒントのカードを出します。
- カードの「閉じる」で閉じ、「詳しく」で「遊び方」の該当する節を開けます。「もう表示しない」を押すと、以後のヒントはすべて出なくなります。

### 操作の表記を直し、「おまかせ」を削除しました

- 演出を飛ばすボタンを「演出をスキップ」に統一しました（画面下の操作行と、出目調整のダイアログ）。
- 出目調整のダイアログでは、「Escapeキーでも『そのまま』で続けます。」の案内を、マウスなどの細かいポインターがある環境だけに表示します。
- 終点の説明を「終点に着くと、出目が余っていてもそこで止まります。」に改めました。ヒント、「遊び方」、ルールの説明で表現をそろえています。
- 自動でサイコロを振る「おまかせ」は、正しく動いていなかったため削除しました。操作行は「サイコロを振る」と「演出をスキップ」の2つです。

**途中のセーブデータと設定について**

セーブデータの形式と路線データは変わらないため、更新前の途中のセーブは、そのまま続きから遊べます。「おまかせ」を含む以前の設定も、そのまま読み込めます。

## 公開時の対応（内部メモ）

- 路線データの版（`dataVersion`）は `n02-2025-7974da15af8e` のままです。エンジン・乱数・セーブ形式も変えていません。[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たらないため、予告は要りません。
- 新しい案内の画面を加え、「おまかせ」の操作をなくしたので、アプリの版はマイナー番号で上げます。今回は 0.17.1 → 0.18.0 とします。
- 対応する PR：#114（Issue #67・#113）。develop への取り込みでは Issue は閉じないため、リリース PR の本文に `Closes #67`・`Closes #113` を書いて閉じます。
- 初回かどうかの判定とヒントの既読は、`localStorage` のキー `yamanote-line-sugoroku:guide:{started,coach,hints-disabled,hint:<id>}:v1` に保存します。ブラウザごとの保存なので、別のブラウザや端末では、もう一度初回として扱います。
- 未確認：スマホ実機でのコーチマークとヒントのカードの位置、タッチ操作。
