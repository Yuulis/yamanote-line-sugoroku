# v0.13.1 リリースノート

作成日：2026-11-10。GitHub Releases に載せる本文の元になる文面です。長い日本語が単語の途中で折れないようにし、スマホの HUD を読みやすくしました。ルール・セーブ形式・路線データは変わらないため、[配信とデータ更新の方針](data-update-policy.md)の「大型更新」には当たりません。

## 公開時の本文

### v0.13.1：長い路線名や説明が、読みやすい位置で折り返すように

路線名や方面、ダイアログの説明が「路線 / 名」のように単語の途中で折れていたのを直しました。空白や括弧、「・」の後や「方面」の前など、区切りのよい位置で折り返します。ルールは変わらず、出目や抽選の結果も今までと同じです。

**スマホの HUD**

- 「乗車中」と「進行方向」は、長い名前でも2行まで表示し、それ以上は「…」で省略します。
- 値とラベルの文字を一回り大きくしました。
- 名前の長さが変わっても、サイコロのボタンの位置は動きません。

**ダイアログとクリア画面**

- アイテムを使うときの路線・方向の選択や、出目調整の説明が、読みやすい位置で折り返します。
- クリア画面の結果の文と移動履歴も、同じように折り返します。
- ボタンの文字は1行のままです。幅が足りないときは、ボタンごと次の行に並びます。

**ご注意**

- 幅の狭いスマホでは、とても長い方面名（羽田空港第1・第2ターミナル方面など）は、途中で折れたうえで省略されることがあります。全文はログで確認できます。
- パソコンの HUD は今までどおり1行で、長い名前は「…」で省略します。
- 以前のセーブデータは、そのまま続きから遊べます。

## 公開の判断（内部メモ）

- 表示の崩れの修正と読みやすさの改善で、新しい機能は加えていないため、アプリの版はパッチ番号で上げる（0.13.0 → 0.13.1、作者の判断）。
- 凍結中の項目（路線データ、ルール、セーブ形式）は変えていないので、[大型更新](data-update-policy.md)には当たらない。予告は不要で、GitHub Releases への本文掲載だけで足りる。
- 対応する PR は #79（`feature/text-wrapping`、Issue #70）。
- 折り返しは表示だけの処理で、`title`、読み上げ用の文、セーブ、共有文の文字列は変えていない。
- 両端揃えも試したが、文字間が不自然に広がる行が出るため採用しなかった（`.claude/docs/DESIGN.md` 2026-11-10）。
- 未確認：iPhone 実機の Safari での折り返し位置。CI の WebKit（デスクトップ幅）と、テスト内でスマホ幅にした確認は通過している。
