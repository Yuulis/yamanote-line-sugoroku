# エディション切替の実装状況

## 現在の対応

ゲームはデータ、ルール設定、表示文、セーブ領域をエディション単位で
扱います。現在登録されているのは「東京近郊版」のみです。このため、
タイトル画面には版選択欄を表示せず、従来のタイトル表示を維持します。

複数の版が登録された場合、タイトル画面の「遊ぶ版」から選択できます。
選択を変えると、その版のデータを読み込み直し、ロード中やデータ不備の
場合も選択欄を利用できます。切替時には前のロード結果を破棄し、路線の
表示絞り込み状態を初期化します。

## セーブデータ

各版は独立したセーブ領域を使います。東京近郊版は従来の
`yamanote-line-sugoroku:save:v1` を引き続き使用します。版を切り替えた
だけではセーブを書き換えたり削除したりしません。別の版で新規に開始、
保存、削除した操作は、その版の領域だけに反映されます。

## 今後の版追加

山手線のみ、23区、1都3県などの別データはまだ含まれていません。追加時は
schema v3 のデータ一式、ゲーム設定、駅数の期待値、タイトル表示文、固有の
セーブ領域を登録します。現在のゲームエンジンやセーブ形式の変更は必要
ありません。

データの配置と追加手順の概要は [`data/README.md`](../../../data/README.md)
を参照してください。全体の設計判断はリポジトリ内の
`.claude/docs/DESIGN.md` に記録されています。
