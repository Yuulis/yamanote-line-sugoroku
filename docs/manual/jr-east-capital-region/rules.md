# JR東日本 1都3県版の遊び方

東京都・千葉県・神奈川県・埼玉県のJR東日本の運行系統を対象にした版です。新橋から山手線外回りで出発し、山手線の外回り30区間をすべて踏破して新橋に到着するとクリアです。

## 対象サービス

## 対象範囲と含まない路線

対象は東京都・千葉県・神奈川県・埼玉県内のJR東日本の在来線です。新幹線、御殿場線、私鉄、地下鉄、モノレール、りんかい線、島しょ部は含みません。県境では各サービスを最後の対象駅で打ち切り、先の駅や残りの出目は扱いません。久留里線は久留里までです。

湘南新宿ラインは、宇都宮線・横須賀線系統の各停と、高崎線・東海道線系統の快速の2サービスを収録しています。各停と快速系統は抽選で同じ重みを持ちます。プレイヤーが列車種別を選ぶ仕組みはありません。

## 1ターンの流れ

1. サイコロを振り、現在のサービスの停車駅を出目の数だけ進みます。1目は乗車中サービスの次の停車駅までです。
2. 終点、エリア端、または系統の端に着いた時点で止まり、残りの目は破棄します。通過駅では抽選しません。
3. クリアしていなければ、到着駅に停車するサービスから次のサービスを抽選します。山手線が候補にある場合、山手線を1/2で選び、残り1/2を他の候補へ均等に分けます。たとえば候補が山手線と他の3系統なら、山手線は1/2、他の各系統は1/6です。山手線が候補にない場合は全候補から均等に選びます。
4. 山手線では外回りに進みます。他のサービスでは、移動できる方向が2つある場合、次の駅から山手線までのサービス区間数が少ない方向を2対1で選びます。同じ距離なら均等です。片方向しか進めない端点では方向は自動で決まります。
5. 乗車中と同じサービスも抽選候補に含みます。候補や方向が1つだけなら抽選を行いません。

## 踏破とクリア

踏破として数えるのは山手線に乗って通過した外回り区間だけです。他サービスが同じ地図形状を通っても山手線の踏破数には加算しません。30区間を踏破した後、山手線で新橋に到着した場合は途中の出目を打ち切ってクリアします。他サービスでは、出目を使い切って新橋にちょうど止まった場合にクリアします。

## セーブと操作

各ターンの結果は移動アニメーション前に確定して保存されます。移動中に再読み込みしても、到着駅と次のサービス・方向から再開し、抽選をやり直しません。

セーブ形式は `saveVersion: 3`、ルールセットは `jr-east-capital-1` です。旧形式や異なるルールセットのセーブは引き継がれず、未対応形式の案内から破棄できます。

「追尾」で自動追尾を切り替え、「スキップ」で演出を省略できます。地図・鉄道データの出典とライセンスは画面内に表示されます。本作品はJR東日本・国土交通省とは関係のない非公式作品です。
