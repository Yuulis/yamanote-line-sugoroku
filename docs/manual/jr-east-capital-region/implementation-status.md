# JR東日本 1都3県版の実装状況

JR東日本1都3県版は2026-10-15に本番リリースしました（PR #26）。このページはその当時の記録です。現在は東京近郊版を開発中で、このページの件数・確率・リリース状況はいずれも当時のものです。

## 実装済みの内容

- 東京都・千葉県・神奈川県・埼玉県の40サービス、472駅を収録しています。山手線は外回り30駅です。
- ゲーム網は1,224有向区間、568個の所有地図形状、1,230件の区間から形状への参照で構成されます。形状チェーンの最大長は3です。
- すべての駅が新橋から到達でき、新橋へ戻れます。東京駅の京葉線ホーム、武蔵小杉の南武線ホームには確認済みの位置ずれ例外があります。常磐線快速の上野駅では別ホーム間の乗換を1か所設定しています。
- 山手線が乗換候補にある場合の選択確率は1/2、他候補間は均等です。他サービスの方向選択は山手線へ近づく方向を2対1で優先します。
- 各ターンの抽選と移動結果は移動アニメーション前に確定して保存され、`saveVersion: 3` と `jr-east-capital-1` に対応します。互換性のない旧セーブは移行せず、破棄できます。

`public/data/` の5ファイル合計は744,720バイト、gzip（level 9、mtime 0）合計は125,322バイトです。いずれも `capital-region` 予算内です。ファイル別の実測値は次のとおりです。

総量上限は生3,145,728 B・gzip 921,600 Bで、使用率はそれぞれ23.7%・13.6%です。GeoJSON上限は生1,572,864 B・gzip 460,800 Bです。期待カタログは `data/overrides/expected-catalog.json` に固定され、SHA-256は `42bcd19b8407c6d80d45622f0589268b2b0dc7970fdd63fc6f3cc7352ba2a231` です。配布データの `dataVersion` は `n02-2025-82589587088b` です。

S5で現行ルールを配布データ上で再測定した20,000ゲームのモンテカルロ結果は、クリアターン数の中央値61、90パーセンタイル148、99パーセンタイル258です。500ターン超えと上限到達はどちらも0件でした。全候補を均等にする比較設定は396 / 967 / 1,643ターン、500ターン超え7,707件、上限到達0件でした。これは固定シードの測定結果であり、個々のゲーム時間の保証ではありません。

## 既知の地図データ上の限界

国土数値情報N02は一部の並行線路を別々に表現していません。常磐線の綾瀬〜金町、総武快速線・総武緩行線の江戸川橋梁、赤羽〜浦和の宇都宮線・高崎線区間では、実際の線路分離を地図形状だけから確認できない一般化表現を使っています。サービスと停車駅の定義は別々に保持し、これらを物理線路が同一だと示すものではありません。

常磐線快速の上野駅では、到着側と出発側のN02線路形状が連続していないため、レビュー済みのホーム移動を適用します。実測の最大端点距離は約131 mです。東京駅の京葉線ホーム（例外上限500 m）と武蔵小杉の南武線ホーム（例外上限400 m、実測393.4 m）にも代表点との位置ずれがあります。

## 検証とリリース

S5完了時の記録では、Vitest 578件、Playwright E2E 93件、データパイプラインpytest 373件が成功しています。型チェックと本番ビルドも成功し、N02生データからの再生成は `public/data/` と5ファイルすべて一致しました。実データE2Eでは40サービスの地図表示、全駅の全体表示、上野のホーム移動、セーブ復元を確認しています。

S7でスマホの全体表示をパネルの実際の高さに合わせる修正と、この説明書の整備を行いました。統合ブランチは `develop`（PR #25）を経て `master`（PR #26）にマージ済みで、本番のスモークテストは利用者側で実施します。今後の方針案は [development-roadmap/proposal.md](../development-roadmap/proposal.md) にあります。
