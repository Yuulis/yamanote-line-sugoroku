# 東京近郊版の遊び方

新橋から出発し、東京近郊区間のJR線と対象の私鉄・地下鉄を乗り継ぐすごろくです。山手線外回り全30区間を踏破したあと、新橋に到着するとクリアです。サイコロの出目だけ駅を進み、到着駅で次に乗る路線を抽選します。山手線と他の路線がある駅では、3分の2の確率で山手線を選び、残りの確率を他の運行系統に均等に割り当てます。他の路線で方向を抽選するときは、山手線に近づく方向の抽選重みが反対方向の2倍になります。

## 収録範囲

配布データには1,586駅、135の運行サービス、3,988有向区間を収録し、山手線の外回り30区間をクリア目標にします。画面上は15事業者・134路線グループとして表示します。運行サービスと画面表示上の路線は別のまとまりで、大江戸線は環状部と放射部の2サービスを1つの「大江戸線」にまとめ、抽選枠は2つです。都庁前では「大江戸線（抽選枠2）」と表示されます。

駅の同一性は確認済みの乗換駅と別名情報に基づきます。駅名が似ているだけで同一駅とはみなしません。表示名の上書きがある駅は画面上で読みやすい表記を使います。小さい「ヶ」を含む22件の原綴りも保持しています。

## 1ターンの流れ

1. サイコロを振り、乗車中の運行サービスで出目の数だけ次の停車駅へ進みます。
2. 終点・エリア端・系統の端に着いたらそこで止まり、残りの目は使いません。途中で通過した駅では次の路線を抽選しません。
3. クリアしていなければ、到着駅で乗車可能な運行サービスを抽選します。山手線が候補にある場合は3分の2、残りを他候補に均等配分します。山手線が候補にない場合は候補から均等に選びます。乗車中のサービスも候補に含みます。
4. 山手線は外回りに進みます。他のサービスは進行可能な方向が2つある場合、次の駅から山手線までの距離が短い方向を2倍の重みで選びます。同じ距離なら均等です。片方向しかない場合は自動で決まります。
5. 山手線外回り30区間を踏破したあと、山手線で新橋に到着するとクリアです。他の路線では、サイコロの目を使い切った時点で新橋に到着している場合にクリアです。

## 地図・セーブ

地図は開始時に路線網全体を表示します。「追尾」で現在地の自動追尾を切り替えられ、地図を手で動かすと追尾はOFFになります。「路線の表示設定」では事業者ごと・路線ごとに表示を切り替えられ、「すべて表示」で戻せます。現在地や踏破状況は凡例を折り畳んでも表示されます。「スキップ」で演出を省略できます。ゲーム結果は移動アニメーションの前に確定し、履歴とともに保存されます。

セーブ形式はv3です。以前の形式や異なるルールのセーブは読み込めず、移行も行いません。未対応形式の案内から破棄して新しいゲームを始められます。

このゲームは国土交通省「国土数値情報（鉄道データ）」N02 2025を加工した形状を使用します。一般化された線形のため、一部の並行線路を別々に表現できない場合があります。データ出典と検証手順は[データREADME](../../../data/README.md)を参照してください。
