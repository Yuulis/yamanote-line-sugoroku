# 東京近郊版の遊び方

新橋から出発し、東京近郊区間のJR線と対象の私鉄・地下鉄を乗り継ぐすごろくです。山手線外回り全30区間を踏破したあと、新橋に到着するとクリアです。サイコロの出目だけ駅を進み、到着駅で次に乗る路線を抽選します。山手線と他の路線がある駅では、2分の1の確率で山手線を選び、残りの確率を他の運行系統に均等に割り当てます。他路線での方向抽選は、山手線へ近づく方向と反対方向の重みが3：2です。

## 収録範囲

配布データには1,586駅、135の運行サービス、3,988有向区間を収録し、山手線の外回り30区間をクリア目標にします。画面上は15事業者・134路線グループとして表示します。運行サービスと画面表示上の路線は別のまとまりで、大江戸線は環状部と放射部の2サービスを1つの「大江戸線」にまとめ、抽選枠は2つです。都庁前では「大江戸線（抽選枠2）」と表示されます。

駅の同一性は確認済みの乗換駅と別名情報に基づきます。駅名が似ているだけで同一駅とはみなしません。表示名の上書きがある駅は画面上で読みやすい表記を使います。小さい「ヶ」を含む22件の原綴りも保持しています。

## 1ターンの流れ

1. 使いたい券があれば、サイコロを振る前に1つ選びます。使わずに進めてもかまいません。
2. サイコロを振ります。出目調整券を持っていれば、出目を見てから±1するか、そのまま進むか選べます。すでに別の券を使ったターンは調整できません。
3. 乗車中の運行サービスで停車駅を数えて進みます。終点・エリア端・系統の端で止まり、残りの目は使いません。途中駅では次の路線の抽選やアイテムの取得は行いません。
4. クリアしていなければ、到着駅で次に乗る運行サービスを抽選します。山手線と他のサービスが候補に並ぶ場合は山手線が1/2、残りを他の候補で等分します。山手線がない場合は均等です。乗車中のサービスも候補に含みます。
5. 山手線は外回りです。他のサービスでは、次の駅から山手線までの距離が短い方向と反対方向を3：2で抽選します。同距離なら均等、片方向しかなければ自動で決まります。
6. ターンの最後に止まった駅で、30%の確率でアイテムを拾います。そのうち30%は不利なアイテムです。有利な7種類・不利な4種類の中から、それぞれ均等に選びます。クリアしたターンには拾いません。

山手線外回り全30区間を踏破したあと、山手線では新橋に着いた時点で止まってクリアします。他の路線では移動の最後に新橋へちょうど止まる必要があります。

## アイテム

有利なアイテムは最大3つ持てます。満杯のときに新しく拾ったら、手持ち3つと新しいものの計4つから1つを選んで捨てます。不利なアイテムは持ち物に入らず、拾うと効果が予約・適用されます。

自分で使えるアイテムは1ターンに1つです。出目調整券以外はサイコロを振る前に使います。遅延・寝過ごしが発動するターンには使えません。遅延証明書は持っているだけで働き、自分で使う1つには数えません。

| 名前 | 効果・使うタイミング |
| --- | --- |
| 路線指定券 | 今いる駅で乗る運行サービスを選びます。向きは抽選です。運休中のサービスは選べません。 |
| 方向指定券 | 山手線以外のサービスで進む向きを選びます。山手線は外回り固定です。 |
| 出目調整券 | 出目を見てから±1します。1未満・6より大きい目にはできません。 |
| 倍速券 | このターンの出目を2倍にします。 |
| 快速券 | 2サービス以上が止まる駅だけを1マスと数えます。通過する駅間も移動回数と踏破に数えます。 |
| 回送列車 | サイコロを振らず、路線網上で最も近い山手線の駅へ移ります。移動回数は0、ターン数は1増え、途中区間は踏破になりません。 |
| 遅延証明書 | 持っていると次に拾う不利なアイテムを1回打ち消し、証明書を消費します。持ち物の枠を1つ使います。 |
| 遅延 | 拾ってから3ターン後の出目が1になります。 |
| 運休 | 到着駅のサービスの1つが5ターン乗換候補から外れます。すでに乗っている列車は降ろされません。候補がすべて運休なら、その駅では運休を無視して抽選します。 |
| 寄り道 | 次の乗換駅では、それまで乗っていたサービスを候補から外します。別の候補がない駅では持ち越します。 |
| 寝過ごし | 次のターンは終点まで進みます。環状線では6駅進みます。遅延と重なったときは寝過ごしを優先し、そのターンの遅延も消費します。 |

路線指定・方向指定の選択画面には、次の駅から山手線までの距離や山手線に近づく方向が表示されます。快速券には山手線へ近づくかどうか、回送列車には移動先が表示されるので、券を使う前に確認できます。

結果の表示・共有は「東京近郊版」のままで、所要ターン数・移動回数（実際に進んだ駅間数）・乗換回数を示します。路線指定券や回送によって路線グループが変わった場合も乗換に数えます。大江戸線の環状部・放射部間など同じグループ内の変更は数えません。

## 地図・セーブ

地図は開始時に路線網全体を表示します。「追尾」で現在地の自動追尾を切り替えられ、地図を手で動かすと追尾はOFFになります。「路線の表示設定」では事業者ごと・路線ごとに表示を切り替えられ、「すべて表示」で戻せます。現在地や踏破状況は凡例を折り畳んでも表示されます。「スキップ」で演出を省略できます。出目の確定、調整・捨てる券の選択、移動結果を順に保存します。再読み込みしても同じ出目・選択待ち状態から再開でき、アニメーション中なら確定済みの到着地点から再開します。

セーブ形式はv4です。以前の形式や異なるルールのセーブは読み込めず、移行も行いません。未対応形式の案内から破棄して新しいゲームを始められます。

このゲームは国土交通省「国土数値情報（鉄道データ）」N02 2025を加工した形状を使用します。一般化された線形のため、一部の並行線路を別々に表現できない場合があります。データ出典と検証手順は[データREADME](../../../data/README.md)を参照してください。
