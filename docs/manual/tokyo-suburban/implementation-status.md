# 東京近郊版の実装状況

この作業ブランチでは東京近郊版を実装・検証しています。ブランチは未リリースで、S8の統合・CI・配信確認が残っています。旧版の公開状況を現行版のリリース根拠として扱わないでください。

## 配布内容

- `dataVersion`: `n02-2025-8a0970069659`、ルールセット: `tokyo-suburban-1`、セーブ形式: v3。
- 配布データは1,586駅、135サービス、2,142サービス停車行、3,988有向区間、山手線目標30区間です。`uiPresentation` は15事業者・134 UI路線グループ、46駅の別名、90サービス停車駅名の表示上書きを持ちます（うち22件は小さい「ヶ」を含む原綴り）。
- 大江戸線の環状・放射サービスは画面では1つの大江戸線にまとまり、都庁前などの抽選候補では2枠として表示されます。
- 旧形式または異なるルールセットのセーブは移行せず、破棄できます。

## ブラウザ・配信確認

Playwrightのローカル既定は2 workersです。地図中心の実データテストは1・2 workersで各2回成功し、4 workersでは30件中7件・6件がタイムアウト、ブラウザ終了等で失敗しました。全体スイートは既定値で2回成功し、各回121 passed・2 project skipsでした。失敗は7 GB WSL2のソフトウェアWebGL下で並列度を上げた際に発生しています。Firefoxが `AllowWebgl2:false` となるWSL2環境では、古い `WAYLAND_DISPLAY` を外して `env -u WAYLAND_DISPLAY npx playwright test` を実行します。CIは2 workersとxvfbを使います。

ローカルVite previewでは5データ資産すべての展開後バイトが `public/data` と一致しました。JSONはgzipされますが `segments.geojson` は `application/geo+json` のまま圧縮されず、1,288,259 Bでした。Vercel上の実ヘッダー・圧縮・キャッシュ・ハッシュはS8で確認します。

物理端末での性能とタッチパン操作は未確認です。main JS chunkは1.32 MBでViteのサイズ警告が残ります。N02の一般化形状は一部並行線路を区別しません。現行版は未リリースで、S8が完了するまで本番反映済みとは扱いません。
