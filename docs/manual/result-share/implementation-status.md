# クリア結果の共有

## 実装状況

クリア画面に「結果をコピー」ボタンを追加しました。Web Share API が使え、共有テキストを `navigator.canShare` が拒否しない場合は「共有」ボタンも表示します。共有結果に使うターン数・移動回数（駅間）・乗換回数は、クリア画面と同じ `summarizeGame` の値です。

## 共有テキスト

現在の版での形式は次のとおりです。版名はエディション登録のタイトルとサブタイトルから作ります。

```text
山手線すごろく 東京近郊版をクリア！
所要ターン数 61・移動回数 240・乗換回数 35
#山手線すごろく
https://yamanote-line-sugoroku.vercel.app
```

実際の数値はクリアしたゲームの結果に置き換わります。日付やリプレイ用リンクは含みません。

## 失敗時

コピーまたは共有に失敗した場合は、失敗したことと下の文面を選択してコピーする案内を表示します。共有文面はラベル付きの読み取り専用テキスト欄に表示され、選択して手動でコピーできます。共有シートをプレイヤーが閉じた場合は、エラーとして扱いません。
