## ver.0.13.1 時点
コードで確認した内容と、推測を分けて書く。

- 確認: 持ち物に入るアイテムは、PCではホバー・フォーカスでツールチップ、クリック・タップでカードが開き、説明が読める（`src/features/game/components/InventoryPanel.tsx:262-305`、ver.0.11.0 から）。
- 確認: 持ち物に入らない不利なアイテム（遅延・運休・寄り道・寝過ごし）は、トーストと効果チップにしか出ない。
  - トーストは今も「{名前}を拾ってしまった！」だけ（`src/features/game/toastQueue.ts:71-73`）。運休だけは「{路線}が運休！」。
  - 効果チップは `<span title=…>` で、押しても何も開かない（`src/features/game/components/EffectChips.tsx:14`、文言は `src/features/game/hudPresentation.ts:103`）。
  - 効果の全文は、初期状態で閉じているログドロワーの中にある（`src/features/game/components/TurnLogDrawer.tsx:82-83`）。文面は `src/features/game/presentation.ts:137-141` と `:150-153` にあり、トーストにもそのまま使える。
- 確認: 入手確率は30%、そのうち不利が30%のまま（`src/features/game/gameConfig.ts:28-30` の `dropChancePerMille: 300`、`harmfulChancePercent: 30`）。
- 確認: 出目調整は±1だけ（`src/features/game/itemSession.ts:203` の `allowedDeltas: (-1 | 1)[]`、`src/features/game/components/RollAdjustment.tsx:20`）。アイテムは有利7種・不利4種のまま（`src/types/network.ts:92-95`）。
- 確認: 入手確率・アイテムの種類・調整幅を変えると、ルールの設定が変わるので、遊んでいる途中のセーブは「ルールが異なるセーブデータのため読み込めません。」になる（`src/features/game/engine/save.ts:340-372` の `sameConfig`、`src/features/game/store/persistence.ts:57`）。移行の仕組みはない（`docs/manual/tokyo-suburban/rules.md`「地図・セーブ」）。
- 推測: 入手確率を上げると、ゲームの長さ（不利なアイテムの回数も増える）と持ち物が満杯になる頻度が変わる。アイテム導入後のゲーム長はまだ測り直していない（#73）。

## 指針
- PCはホバー時に、タブレット・スマホはタップ時に説明用のテキストを表示する。持ち物に入らないアイテムと効果チップも同じ扱いにする。
- 入手確率を50%くらいまで増やす。
- 出目調整券は、±1以外にも±2~3くらいのものまであってもよさそう。
- 説明の改善（表示だけ）と、ルールの変更（確率・種類・調整幅）は分けて出す。ルールの変更は途中のセーブを読めなくするので、まとめて1回にする。
- ルールを変えるときは、セーブ形式も変える。途中のセーブが読めなくなるのは許容し、移行の仕組みは作らない（2026-11-10 決定）。

## 案
### 説明を見られるようにする（表示だけ）
- 効果チップをタップ・クリックできるようにし、持ち物と同じカード（またはツールチップ）で説明を開く。持ち物の仕組み（`InventoryPanel`・`ItemCard`）を流用できる。
- 不利なアイテムを拾ったときのトーストに2行目を足し、結果を書く（例:「3ターン後の出目が1になります」）。文面は `presentation.ts:137-141` を流用できる。
- 同じ「タップで説明」の仕組みは、#68 のセーブの ✓ にも使える。

### 入手確率
- 入手確率を50%くらいまで増やす。
- 変える前に `npm run sim` で、30%と50%のゲーム長（中央値・p90・p99）と、満杯で捨てる回数を比べる。#73 の測り直しと一緒にやる。
- 不利の割合（30%）も合わせて見直すか決める。

### 種類を増やす
- 出目調整券に±2・±3の版を足す（別のアイテムにするか、同じ券で幅を選べるようにするか）。
- 新しい種類の案は、ここに追記していく。

### ルールを変えるときの扱い
- `rulesetVersion` を上げ、古いセーブは「ルールが変わったため続きから遊べません」と分かる案内にする。今の案内（`persistence.ts:57`）で足りるか確認する。
- タイトルのルール文と詳細画面（#60）、`docs/manual/tokyo-suburban/rules.md` の数字を同時に直す。

関連: 初めて不利なアイテムを拾ったときのヒントは #67、捨てる操作の確認は #71、前のターンの結果に拾ったアイテムを出すのは #66 で扱う。

優先度の目安: 効果チップとトーストの説明は中（小さく、毎回の不満に効く）。入手確率と種類の追加は低〜中（ゲームバランスとセーブの互換に関わるので、シミュレーションの後に）。
